## 🛠️ Technology Stack (तकनीकी संरचना)

* **Language:** TypeScript
* **Styling:** Tailwind CSS (Vedic Spiritual Color Palette)
* **Icons:** Lucide React
* **Deployment:** Vercel (Auto-deployment via GitHub)

## 🚀 Local Development (लोकल रन करने की विधि)

```bash
# 1. Install dependencies
npm install

# 2. Start development server
npm run dev

# 3. Build for production
npm run build

# 4. Start production server
npm run start
```
Server runs on: `http://localhost:3000`
